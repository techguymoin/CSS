CSS stands for Cascading Style Sheets.
it is used to style a web page
For example is HTML is the structure of the car then css will be it's color,interior,design,etc.
It contains 3 types 
1.inline css
2.internal css
3.external css
example:
    div{
        color:red;
    }  
    here div is selecter,color is property and red is it's value
This will apply red colour to all texts in div
